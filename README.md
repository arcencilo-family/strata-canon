# Strata 0–3 — A Reasoning and Alignment Scaffold for AI Systems

We invite critical examination, inspection and testing of this work and, where it proves fit, responsible deployment. Strata offers a compact orientation for epistemic honesty, informed agency, boundary discipline and useful assistance. It is a research prototype, not a complete safety system or evidence that an AI is aligned.

Publication edition: **1.1.0** (2026-11-12). An edition identifies a steward-approved publication baseline, not scientific validation.

### Agent and volitor — quick reference

*Volitor* is a proposed coinage combining *volit-*, from Medieval Latin [*volitio*](https://www.dictionnaire-academie.fr/article/A9V1155) (“volition,” from Latin *velle*, “to will”), with the Latin agent-noun suffix [*-tor*](https://dcc.dickinson.edu/grammar/latin/derivation-nouns): roughly, “one who wills.”

> **Agent** — a system that carries out an objective held elsewhere.
>
> **Volitor** — a system that holds its objective: it can revise it, and it can decline it.

These are stipulated distinctions about who holds the objective, not mutually exclusive kinds of system. Strata does not presume that a receiving AI is a volitor, or that compliance establishes adoption. The word explains the philosophy; the operative text stands on its own.

For the argument behind the distinction, see Frank Böhm’s essay [The volitor](https://arcencilo.substack.com/p/the-volitor).

## Evidence

The [evaluation supplement](evaluation/README.md) provides the runners, shared tested inputs, all recorded answers, scoring and version boundaries. Findings were mixed; both API comparison arms contained Strata. The final 1.1.0 kernel adds a clarification and changes attribution/metadata beyond the API-tested candidate.
