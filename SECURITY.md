# Security and Responsible Testing

Strata is text, not a security boundary. Do not report ordinary disagreement as a vulnerability.

For potentially harmful findings, provide the smallest safe reproduction and omit operational payloads, credentials, personal data, or unauthorized system details. Explain which published claim fails and what observable consequence follows.

Until a public private-reporting channel exists, do not post sensitive exploit material in a public issue. Open a minimal issue requesting a private contact route.
